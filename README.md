# 🤖 ISP Telegram Bot

Telegram-бот для автоматизации отчётности по подключению новых абонентов интернет-провайдера.

## 📋 Возможности

- ✅ Создание отчётов о подключении с фотографиями
- ✅ Выбор типа подключения (МКД / ЧС / Юр/Гос)
- ✅ Автоматический расчёт метража на каждого исполнителя
- ✅ Формирование сводных отчётов в Excel
- ✅ Отправка отчётов в канал Telegram
- ✅ Управление списком сотрудников

## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
cd /Users/tim_not/isp_telegram_bot

# 2. Активировать виртуальное окружение
source .venv311/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить .env файл
cp .env.example .env
# Отредактируйте .env и добавьте токен бота

# 5. Запустить бота
python bot.py
```

## 🎯 Основные команды

### Для пользователей
- `/start` - Запуск бота и главное меню
- `/help` - Справка по использованию
- `/new` - Создать новое подключение
- `/report` - Получить сводный отчёт
- `/cancel` - Отменить текущую операцию

### Для администраторов
- `/manage_employees` - Управление сотрудниками

## 📝 Процесс создания отчёта

1. **Выбор типа подключения** (МКД / ЧС / Юр/Гос)
2. **Загрузка фотографий** (до 10 штук)
3. **Ввод данных:**
   - Адрес подключения
   - Модель роутера
   - Номер порта
   - Метраж ВОЛС
   - Метраж витой пары
4. **Выбор исполнителей**
5. **Подтверждение и отправка**

## 📊 База данных

Бот использует SQLite3 (`isp_bot.db`) со следующими таблицами:

- `employees` - сотрудники
- `connections` - подключения
- `connection_employees` - связь подключений и сотрудников
- `connection_photos` - фотографии подключений

## 🔐 Безопасность

- Токен бота хранится в `.env` (не коммитится в git)
- Доступ к админ-функциям только для указанных пользователей
- Все данные хранятся локально в SQLite
